# Manuscript figure workflows

## Figure contract

The figure set supports one central conclusion: chromosome-scale assembly is
supported by Hi-C, comparative genomic and annotation evidence describe the
assembled genome, and the variant pipeline reproducibly produces the final
SNP set and five-track chromosome summary.

The layout archetype is an asymmetric mixed figure: quantitative chromosome
plots carry the primary evidence, while compact workflow diagrams document
how their inputs were generated. All new plotting, preview and export steps use
R. PDF and SVG preserve editable text; TIFF and PNG are rasterized at the
requested resolution.

## Scripts and source data

| Figure | R entry point | Required source data |
|---|---|---|
| Whole-genome Hi-C heatmap | `analysis/hic/plot_sparse_contact_heatmap.R` | X/Y/Z contact table, chromosome breaks and labels |
| BUSCO completeness summary | `analysis/assembly/plot_busco_summary.R` | per-sample single-copy, duplicated, fragmented and missing counts |
| Five-track SNP Circos | `analysis/circos/plot_snp_tracks.R` | chromosome sizes and the five interval tracks generated by `prepare_tracks.py` |
| CA7301/B73 comparative Circos | `analysis/circos/plot_comparative_genome.R` | sector table, TE density, gene density, LAI and synteny links |
| Annotation workflow | `analysis/schematics/plot_annotation_workflow.R` | no quantitative data; diagram content is encoded in the script |
| SNP calling and hotspot workflow | `analysis/schematics/plot_snp_workflow.R` | no quantitative data; reviewed parameters are command-line options |

The public five-track Circos output uses direct labels `a` through `e` and the
matching center key. The unlabelled draft is not retained as the primary
manuscript preview.

The comparative plot reconstructs the missing plotting layer from the retained
TE-density, gene-density, LAI and NUCmer-collinearity analyses. It does not
invent quantitative results: every plotted interval or link must be supplied
as a tabular input.

## Reviewed parameter decisions

The supplied draft SNP workflow image shows 500-kb windows, 50-kb steps and a
threshold of more than 50 SNPs. The retained final analysis and final density
plots instead use 200-kb windows, 20-kb steps and a strict `count > 100` hotspot
rule. The public R diagram therefore defaults to 200/20/>100. Alternative
values remain explicit command-line options for historical reconstruction.

The retained legacy hard-filter script encoded `HaplotypeScore < 13`, whereas
the supplied workflow image encodes `HaplotypeScore > 13`. The public joint
calling configuration now defaults to the reviewed upper-tail expression
`HaplotypeScore > 13`; the operator remains configurable so a legacy rerun can
be labelled unambiguously.

The post-dedup BAM filter shown in the workflow image is implemented in
`sentieon_gvcf.py`. It retains properly paired, mapped primary alignments with
mapping quality at least 20, excludes supplementary alignments, requires
`NM <= 1`, and limits the number of CIGAR operations to two. The implementation
searches all optional SAM fields for the NM tag rather than assuming a fixed
column.

## Reproducible synthetic test

Install the R packages `ggplot2`, `RColorBrewer`, `circlize` and `svglite`, then
run:

```bash
python scripts/run_example_smoke_tests.py
```

The smoke test generates deterministic ten-chromosome source tables in a
temporary directory and executes all six R workflows. It requires twelve output
files (PDF and PNG for each workflow) to exist and to exceed a minimum size.
No synthetic outputs are committed to the repository.

For a direct four-format export, use the figure-specific command, for example:

```bash
Rscript analysis/circos/plot_snp_tracks.R \
  --track-dir /path/to/circos_tracks \
  --chrom-sizes /path/to/chrom.sizes.tsv \
  --output-prefix /path/to/figure_snp_circos \
  --formats pdf,svg,png,tiff \
  --dpi 600
```

## Visual QA and publication risks

- Chromosome order, direction and naming must match across all source tables.
- Hi-C values are displayed as `log10(KR + 1)` with a default upper scale of 4.
- Circos density tracks are normalized independently for display; source values
  remain in the input tables and must accompany a publication archive.
- The synthetic fixtures exercise layout and parsing only and are not evidence
  for the manuscript.
- Before submission, rerun the scripts on the final source tables and inspect
  PDF/SVG text editability, label overlap, final-size readability and all figure
  legends.
